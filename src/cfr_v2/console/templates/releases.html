Releases are files in registry/releases/, changed through git. A release is pinned when the first case is admitted under it; each case run keeps the version it was admitted with. Making one current sets CFR_RELEASE_ID in .env: new cases are admitted under it, and the next jobs use it. A running worker keeps the procedure snapshot it opened, so if the snapshot changes, restart it once the old release's runs are done.
